# CAS の実行時型ディスパッチ

この文書は、静的型だけでは CAS の型クラスインスタンスを選べない呼び出しを、値の外形から
実行時に解決する現在の仕様を定める。一般の実行時多重ディスパッチではなく、
`MathValue` を境界とする限定的な補助機構である。

## 1. 使われる場合

通常の型クラス呼び出しは、型推論後に静的なインスタンス辞書へ変換する。単一パラメータの
クラスで次の条件を満たす場合だけ、`TypeClassExpand.hs` は
`TIRuntimeDispatch` を生成できる。

- 第1型引数が `MathValue`、または CAS 層で同様に扱う `Integer` である。
- そのクラスに `MathValue` の静的インスタンスがない。
- `MathValue` 以外に、実行時の候補となる単一パラメータインスタンスがある。

多引数クラスはこの経路を使わず、全ての型引数による静的な選択を行う。

## 2. 浅い実行時型

`Type/RuntimeType.hs` の `runtimeTypeOfCAS` は、CAS 値の外側と、その直下の係数・分子・
分母だけを調べる。内側の `Poly` と `Frac` は `MathValue` にまとめる。

```text
CASInteger                 -> Integer
CASFactor                  -> Factor
単項の CASPoly             -> Term <浅い係数型> <原子集合>
複数項の CASPoly           -> Poly <浅い係数型> <原子集合>
CASFrac n d                -> Frac <n と d の浅い共通型>
内側に現れる CASPoly/Frac  -> MathValue
```

例えば、分数の内側に多項式があっても `Frac (Poly Integer [x])` までは復元せず、
`Frac MathValue` と判定する。より深い構造で処理を分けたいインスタンスは、その本体で値を
パターンマッチして分解する。

ここで「浅い」とは、型構成子を再帰的に深く辿らないという意味である。多項式の係数と
原子集合を求めるため、外側の項と単項式は走査する。したがって計算量は値全体に対して
常に定数ではなく、外側の多項式表現の大きさに比例する。

`inspect` などが示す観察型と、このディスパッチ用の浅い型は目的が異なるため、深い CAS 値で
一致しない場合がある。

## 3. 候補の選択

実行時候補は、インスタンスの第1型引数と辞書名の組である。`MathValue` 自身の候補は、
同じ実行時ディスパッチを繰り返すことを防ぐため候補表から外す。

値から得た型を `t`、候補型を `u` とすると、CAS の部分型関係で `t <: u` となる候補だけを
残し、その中から最も具体的なものを選ぶ。部分型関係には組み込みの CAS 型順序と
`declare cas-subtype` の宣言辺を使う。最も具体的な候補が一意に決まらなければ選択失敗とする。

候補数を `N` とすると、現在の最具体候補の比較は候補間の比較を行うため最悪 `O(N^2)` である。
通常はインスタンス数が小さいことを前提とし、辞書表の定数時間検索を主張しない。

## 4. 評価

`Core.hs` の `IRuntimeDispatch` は次の順に評価する。

1. 第1実引数を一度だけ弱頭正規形まで評価する。
2. CAS 値であることを確認し、浅い実行時型を計算する。
3. 最も具体的な候補辞書を選ぶ。
4. 選んだ辞書からメソッドを取り出し、評価済みの第1引数を再利用して適用する。

第1引数を再評価しないのは、再帰的な微分などで同じ計算が倍増するのを防ぐためである。

候補が見つからず、対応する `MathValue` 辞書が実行環境に存在する場合は、その辞書へ
フォールバックする。この辞書内の呼び出しは静的型が `MathValue` なので新しい
実行時ディスパッチ節を生成せず、同じ場所を循環しない。辞書も存在しなければ実行時エラーになる。

## 5. 保証範囲と制限

- 対象は CAS 値だけである。一般の代数的データ型には適用しない。
- 実行時に調べるのは第1引数だけである。
- 実行時候補は単一パラメータのインスタンスだけである。
- 深い型の違いは `MathValue` にまとめるため、深い特殊化は選べない。
- 静的にインスタンスが一意に決まる呼び出しは、従来どおり辞書へ直接変換する。
- この機構は型が一致しなかった式を後から受理するものではない。型推論と制約解決が認めた
  `MathValue` 境界だけを実行時に具体化する。

## 6. 実装箇所

- `Type/RuntimeType.hs`: CAS 値から浅い型を計算する。
- `Type/TypeClassExpand.hs`: 候補表の作成と `TIRuntimeDispatch` の挿入。
- `IExpr.hs`: `TIRuntimeDispatch` と `IRuntimeDispatch` の内部表現。
- `Core.hs`: 候補選択、辞書アクセス、第1引数を再利用する評価。
- `Type/Subtype.hs`, `Type/Instance.hs`: CAS 部分型関係と最具体候補の選択。

型クラス全体の仕様は [type-class.md](./type-class.md)、CAS 型順序は
[type-cas.md](./type-cas.md) を参照する。
