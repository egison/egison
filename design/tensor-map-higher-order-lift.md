# 高階引数の変換と関数定義の候補

高階引数とは，別の関数へ引数として渡す関数である．利用者は，引数型，返り値型，テンソルを受け取る位置，候補の名前を指定しない．

## 通常の型と変換候補

テンソルの要求がなければ，高階関数を使う定義も通常の型を保つ．

```egison
def sum xs := foldl (+) 0 xs
-- 通常の型：[Integer] -> Integer

def increments xs := map (\x -> x+1) xs
-- 通常の型：[Integer] -> [Integer]
```

定義には，高階引数を変換する候補も保持する．候補は型，コード，内部の型変数の共有と制約を一緒に持つ．組合せを先にすべて展開せず，コードと制約を表すテンプレートとして保持できる．

```egison
-- sum のテンソル用候補
\xs -> foldl (\x y -> tensorMap2 (+) x y) 0 xs

-- increments のテンソル用候補
\xs -> map (\x -> tensorMap (\n -> n+1) x) xs
```

候補は元の定義の本体から生成する．本体が分からない関数について，別の実装の存在を仮定しない．

## 受け取り側の型を満たす条件

変換後の関数型が，受け取り側の型変数への一貫した代入によって適合する場合だけ選択できる．同じ型変数のすべての出現と，ほかの引数の要求も照合する．

```text
map    : (a -> b) -> [a] -> [b]
foldl  : (b -> a -> b) -> b -> [a] -> b
filter : (a -> Bool) -> [a] -> [a]
```

`map` は `a` と `b` をテンソル型にできる．`foldl` は結果の `b` を累積値にも共有するため，入力と結果への変換を一緒に検査する．`filter` の結果は `Bool` に固定され，`Tensor Bool` へ変更できない．したがって，`p : Integer -> Bool` を `\x -> tensorMap p x` に変換して `filter` へ渡すことはできない．もともとテンソル全体を受け取って `Bool` を返す述語は使える．

高階関数全体の結果がリストになる `map` でも変換を許す．判定に必要なのは，各型変数と固定された型の整合である．

## 使用ごとの選択

各参照では通常の候補を優先し，使用箇所の制約を満たさなければ変換候補を選ぶ．一般化した型変数は参照ごとに新しくする．外側から捕捉した単相な変数は，同じ型の関係を共有する．

```egison
(sum [1,2], sum [[|1,2|],[|3,4|]])
-- (Integer, Tensor Integer)
-- (3, [|4,6|])

let f := sum in
  (f [1,2], f [[|1,2|],[|3,4|]])
-- 同じ二つの候補を使用できる
```

直近の引数だけで候補を確定しない．後続の引数，高階引数，let の使用によって不一致が分かった場合も，型代入と制約を戻して選び直す．選択のためにプログラムを実行しない．

捕捉した値には定義位置で一意な内部名を付ける．候補のコードを使用位置へ展開しても，そこで同じ名前の変数が束縛されていることによって，捕捉した値が変わらないようにする．

部分適用の返り値が関数のテンソルである場合も，`Tensor` を保持して照合する．残る引数は保存された関数へ写像によって適用し，もともとテンソルを受け取る仮引数には，全体のテンソルを渡す．明示的な `tensorMap` の入力も，型を正規化する前の成分だけへ分解して確定せず，テンソル全体の等式として解く．`Tensor a` の `a` がテンソルである可能性を保ち，後続の制約に応じて選び直す．

## 未確定の仮引数

```egison
\k -> k [|1,2|]
-- (Tensor Integer -> a) -> a

\k -> tensorMap k [|1,2|]
-- (Integer -> a) -> Tensor a
```

未確定の仮引数にはテンソル全体を渡す．成分ごとの適用は明示的な `tensorMap` で記述できる．

## 実装と検証

`Type/Env.hs` は候補とコード・制約のテンプレートを保存する．`Type/Infer.hs` は参照ごとの具体化，捕捉変数の共有，候補の比較と選び直しを行う．`Type/TensorMapInsertion.hs` の `buildCallbackLiftPlan`，`typeDirectedTensorLiftTypes`，`callbackLiftMask` は，受け取り側の型に適合する入力の部分集合を扱い，選択後に `tensorMap`・`tensorMap2` のコードを生成する．

スカラー初期値は階数0として受け取れる．`foldl` の初期値 `0` を受け取ることを理由に，結果をさらにテンソルで包まない．`IO`，`IORef`，`Port`，関数型やこれらを含む型は，成分ごとの自動変換の対象にしない．

推論型と挿入は `test/TensorInference.hs`，実行は `test/lib/core/tensor-function-families.egi`，`tensor-higher-order.egi`，`tensor-result-types.egi` で検査する．
